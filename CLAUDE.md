# Market Bot — контекст проекта для Claude

> Переписан 29.09.2026 по итогам аудита: прежняя версия описывала март 2026 («только чтение Bybit», баланс
> 10 000, 24 монеты, флейк8) и вводила в заблуждение. Источники правды по убыванию: прод → код → этот файл.

## Что это

Исследовательская программа торговли на **Bybit (демо-счета)**: гипотезы записываются в
`docs/TRADER_PLAN.md` **до** прогона, проверяются на истории и вперёд, принятые — исполняются на демо.
Python **3.14**, SQLite, FastAPI + Telegram Mini App (React + TypeScript), Docker на одном VPS.

**Сигнальная торговля бота выключена** (`SIGNAL_TRADING_ENABLED` по умолчанию `false`): его стратегии
отвергнуты проверкой Ф2 (−0,33 R). Бот работает коротким циклом — свечи и сообщения о резких движениях.
Перед включением — список в `docs/TECH_DEBT.md` («Сигнальная торговля: не включать как есть»).

Исполнители И14/И18: общий шаг — `portfolio/executor.py` (ордера до цели, повтор только не прошедших

На том же хосте — Supabase проекта deusfin (`/opt/deusfin/supabase`): **не трогать**. Его порты 8000/8443/5432/6543
открыты наружу мимо ufw — решение за владельцем (`docs/TECH_DEBT.md`).

**Секреты по сервисам.** Каждый контейнер получает только свои секреты: карта `deploy/service-secrets.conf` →
`deploy/split-env.sh` собирает `/opt/market-bot/env/<сервис>.env` из общего `.env` перед каждым `compose up`.
Новый секрет в коде — строка в карте (`tests/test_service_secrets.py` ловит пропуск). Замена секрета — шаги
`deploy.sh token | ai-key | bybit-key`: правят общий `.env` и пересоздают ровно те сервисы, которым карта выдаёт
этот секрет (`services_with`). У API ключей биржи нет.

## Как работать

- **Тесты:** `py -m pytest tests/` (pytest.ini уже даёт `-q`; второй `-q` прячет строку «N passed»).
  Тесты не ходят в сеть и не пишут владельцу (`tests/conftest.py` делает это ошибкой).
  Бюджет теста — единицы секунд: в CI таймаут 120 с на тест, раннер медленнее машины разработчика. Тяжёлые сценарии
  (прогон генератора, широкий кэш) — на подмножестве; неизбежно долгий тест — с явным `@pytest.mark.timeout(N)` и
  причиной. CI печатает 10 самых долгих (`--durations`). 30.09.2026 тест с тремя полными прогонами генератора
  (~165 с) упал в CI.
- **Bybit:** адрес — `exchange.bybit_client.MAINNET_REST`, временные коды ответа (лимит, внутренняя ошибка) —
  `TRANSIENT_RET_CODES` там же; своих копий в клиентах не заводить (`tests/test_hardcode_audit.py`).
- **Линт и типы:** `py -m ruff check .` и `py -m mypy` (настройки — `pyproject.toml`; mypy — исполнители).
- **Мутационная проба:** `py -m tools.mutate <файл> <старое> <новое>` (ровно одно вхождение) — мутант ставить в
  саму ветку поведения; оригинал возвращать из памяти процесса, не из копии в temp.
- **Зависимости:** `requirements.txt` + замок с хэшами `requirements.lock` / `requirements-dev.lock` (команда
  пересборки — в шапке замка); `tests/test_lock.py` сверяет их.
- **Окружение:** каждая переменная, которую читает код, описана в `.env.example` (`tests/test_env_example.py`).
- **Изменения:** ветка → PR → зелёный CI → слияние (`deploy/pr_chain.sh`: `ship_branch`, `finish_branch`).
  Выкладка — `DEPLOY_HOST=root@<хост> sh deploy/ship.sh release smoke`, **только по слову владельца**.
  Релиз исполняет ПРЕЖНЯЯ копия `deploy.sh` на сервере (новая ставится после здорового релиза). Изменение, которое
  новый скрипт должен сделать до `compose up` (как файлы окружения пакета 8), выкладывается двумя релизами:
  сначала скрипт, потом то, что от него зависит.

## Принципы сигнального бота (действуют, если его включат)

1. Fail-safe first — блокировка торговли при любой неопределённости.
2. DecisionCore — единственный авторитет решений; SystemGuardian проверяется первым; обходов нет.
3. Критичные модули только fail-closed; изменения архитектуры — через ADR (`docs/adr/`).

## Правила

1. Секреты — никогда в коде, логах, коммитах; токен бота фильтруется из логов (`utils/log_redaction.py`).
2. Правило гипотезы меняется только записью в плане и пересчётом; замороженный код `backtest/` не
   переписывать «попутно» (ruff UP для него выключен).
3. Прод, выкладка, отправки владельцу, платное — только по прямому слову.
